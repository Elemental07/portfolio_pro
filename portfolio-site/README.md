## 🚀 Быстрый старт

### Локальный просмотр

1. **Добавьте своё фото:**
   - Поместите файл `leonard_photo.png` в папку `assets/`
   - Рекомендуемый размер: минимум 152×152px (для Retina-дисплеев)
   - Формат: PNG или JPG

2. **Откройте сайт:**
   - Дважды кликните на `index.html` — откроется в браузере
   - Или перетащите файл в окно браузера

### Деплой на GitHub Pages (рекомендуется для начинающих)

GitHub Pages — это бесплатный хостинг для статических сайтов. Ваш сайт получит адрес типа `username.github.io/portfolio-site`.

#### Шаг 1: Создайте аккаунт на GitHub
1. Перейдите на [github.com](https://github.com)
2. Нажмите "Sign up" и создайте аккаунт

#### Шаг 2: Загрузите проект
1. Войдите в свой аккаунт
2. Нажмите кнопку "+" в правом верхнем углу → "New repository"
3. Назовите репозиторий: `portfolio-site` (или любое другое имя)
4. Выберите "Public"
5. Нажмите "Create repository"
6. На следующей странице нажмите "uploading an existing file"
7. Перетащите **все файлы** из папки `portfolio-site` в окно браузера:
   - `index.html`
   - `styles.css`
   - Папку `assets` с содержимым
8. Нажмите "Commit changes"

#### Шаг 3: Включите GitHub Pages
1. В репозитории перейдите на вкладку "Settings"
2. В левом меню найдите "Pages"
3. В разделе "Source" выберите "main" (или "master")
4. Нажмите "Save"
5. Через 1-2 минуты ваш сайт будет доступен по адресу, который появится вверху страницы

**Готово!** Теперь можно делиться ссылкой на сайт.

### Альтернатива: Netlify Drop (ещё проще)

1. Перейдите на [app.netlify.com/drop](https://app.netlify.com/drop)
2. Перетащите **всю папку** `portfolio-site` в окно браузера
3. Сайт задеплоится автоматически, вы получите ссылку вида `random-name.netlify.app`

**Плюс:** не нужна регистрация для тестового деплоя.  
**Минус:** ссылка случайная, если не зарегистрируетесь.

## ✏️ Как редактировать контент

Все правки делаются в файле `index.html`. Открывайте его в любом текстовом редакторе (Блокнот, Notepad++, VS Code).

### Изменить имя и описание

Найдите строку:
```html
<h1>Leonard<br>Shevchenko</h1>
<p>Мотивированный и надёжный кандидат...</p>
```

Замените текст на свой.

### Изменить контакты

Найдите секцию `<section id="contact"...>`:

```html
<a href="mailto:leonard.shevchenko.07@gmail.com">
  <span>Email</span>
  leonard.shevchenko.07@gmail.com
</a>
```

Замените email на свой. То же с телефоном:

```html
<a href="tel:+4915733784998">
  <span>Телефон</span>
  +49 157 33784998
</a>
```

### Добавить/удалить опыт работы

Найдите секцию `<section id="experience"...>`. Каждый блок опыта выглядит так:

```html
<article class="entry">
  <div class="entry-top">
    <h3 class="entry-name">Praktikant</h3>
    <time class="entry-date" datetime="2022-06">06/2022</time>
  </div>
  <div class="entry-sub">ATU — Landshut</div>
  <ul>
    <li>Монтаж шин...</li>
    <li>Демонтаж и монтаж колёс</li>
  </ul>
</article>
```

Скопируйте весь блок `<article>...</article>`, вставьте ниже и отредактируйте.

### Поменять фото

1. Подготовьте новое фото (PNG или JPG)
2. Назовите его `leonard_photo.png`
3. Замените файл в папке `assets/`
4. Если файл называется по-другому (например, `photo.jpg`), откройте `index.html` и найдите:
   ```html
   <img class="avatar" src="./assets/leonard_photo.png" alt="...">
   ```
   Замените путь на `./assets/photo.jpg`

### Изменить цвета

Откройте `styles.css` и найдите блок `:root` в самом начале:

```css
:root {
  --black: #0A0A0A;   /* Основной чёрный */
  --white: #FFFFFF;   /* Белый фон */
  --grey: #6E6E6E;    /* Серый текст */
  ...
}
```

Замените hex-коды цветов на свои (можно найти в Google "color picker").

## 🔧 Технические детали

- **Валидация:** HTML и CSS соответствуют стандартам W3C
- **Адаптивность:** протестировано на брейкпоинтах 320px, 480px, 640px, 768px, 1024px+
- **Доступность:** alt-тексты для изображений, семантические HTML5-теги, keyboard-навигация, focus-состояния
- **SEO:** meta-теги, Open Graph для превью в соцсетях
- **Производительность:** инлайн критических стилей не требуется (один CSS-файл), шрифты загружаются через Google Fonts с preconnect

- **GitHub Pages не обновляется:** изменения появляются через 1-5 минут после загрузки, очистите кэш браузера (Ctrl+Shift+R)
