# 🚀 Быстрый деплой за 5 минут

## Вариант 1: GitHub Pages (бесплатно навсегда)

### Что вам понадобится:
- Аккаунт на GitHub (создаётся за 2 минуты)
- Эта папка с файлами

### Пошаговая инструкция:

1. **Подготовьте файлы:**
   - ⚠️ ВАЖНО: Добавьте своё фото `leonard_photo.png` в папку `assets/`
   - Если фото называется по-другому, переименуйте его или измените путь в `index.html`

2. **Зарегистрируйтесь на GitHub:**
   - Перейдите на https://github.com/signup
   - Заполните форму регистрации (username, email, пароль)
   - Подтвердите email

3. **Создайте репозиторий:**
   - После входа нажмите зелёную кнопку "New" (или "+" → "New repository")
   - Repository name: `portfolio` (или любое другое имя)
   - Выберите **Public**
   - ❌ НЕ ставьте галочку "Add a README file"
   - Нажмите "Create repository"

4. **Загрузите файлы:**
   - На странице нового репозитория нажмите "uploading an existing file"
   - Перетащите ВСЕ файлы из папки portfolio-site:
     - `index.html`
     - `styles.css`
     - `README.md`
     - `.gitignore`
     - Папку `assets` со всем содержимым
   - Внизу нажмите "Commit changes"

5. **Включите GitHub Pages:**
   - Перейдите на вкладку **Settings** (⚙️)
   - В левом меню найдите **Pages**
   - В разделе "Build and deployment":
     - Source: выберите **Deploy from a branch**
     - Branch: выберите **main** → папка **/ (root)**
   - Нажмите **Save**

6. **Получите ссылку:**
   - Через 1-2 минуты вверху появится зелёная плашка с вашей ссылкой:
     `https://your-username.github.io/portfolio/`
   - Откройте её в браузере — ваш сайт работает!

**✅ Готово!** Теперь при любых изменениях просто загружайте обновлённые файлы в репозиторий.

## Вариант 2: Netlify (проще всего, но ссылка случайная)

1. Перейдите на https://app.netlify.com/drop
2. Перетащите **всю папку** `portfolio-site` в окно браузера
3. Сайт задеплоится за 10 секунд, вы получите ссылку вида `random-name-12345.netlify.app`

**Плюсы:**
- Не нужна регистрация для теста
- Мгновенный деплой

**Минусы:**
- Ссылка случайная (можно изменить после регистрации)
- Сайт удалится через 7 дней без регистрации

---

## Вариант 3: Vercel (для более продвинутых)

1. Зарегистрируйтесь на https://vercel.com/signup
2. Нажмите "Add New..." → "Project"
3. Импортируйте репозиторий с GitHub (если уже загрузили туда)
4. Или нажмите "Deploy" и перетащите папку
5. Получите ссылку вида `portfolio-xyz.vercel.app`

**Плюсы:**
- Автоматический деплой при каждом изменении в Git
- Бесплатный SSL-сертификат
- Очень быстрая загрузка сайта

## 🔗 Что делать после деплоя?

1. **Добавьте ссылку в резюме** под "Контакты" или "Портфолио"
2. **Поделитесь в соцсетях** — Open Graph сделает красивое превью
3. **Отправьте работодателям** — профессиональный сайт выделяет вас среди других кандидатов
4. **Обновляйте контент** — добавляйте новый опыт работы, проекты, навыки

## 🆘 Что-то пошло не так?

### Фото не отображается на сайте
- Убедитесь, что файл называется точно `leonard_photo.png` (без пробелов!)
- Проверьте, что он лежит в папке `assets/`
- Если имя другое, откройте `index.html` и измените строку:
  ```html
  <img class="avatar" src="./assets/leonard_photo.png" ...>
  ```

### GitHub Pages показывает ошибку 404
- Подождите 2-5 минут — сайт не появляется моментально
- Проверьте, что в Settings → Pages выбрана ветка `main`
- Убедитесь, что файл называется `index.html` (не `portfolio.html`!)

### Сайт "поехал" на телефоне
- Откройте сайт на компьютере и нажмите F12
- Кликните на иконку телефона в инструментах разработчика
- Выберите разные размеры экрана (iPhone, Android) для проверки
